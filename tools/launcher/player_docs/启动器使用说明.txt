ドットアビスX 离线启动器 · 使用说明
=====================================

【开始游戏】
  检查离线配置 -> 补齐离线身份与 catalog(本地、秒级) -> 启动游戏(自动跳过 DMM 登录)。
  游戏运行中再点会被拒绝,不会开出第二个实例。

【更新】
  从 GitHub 拉取官方更新(需要联网,失败不影响已安装内容;游戏运行时禁止更新):
  客户端本体(游戏程序/DLL 等,几百 MB,按文件校验只装变化的)、
  素材增量(新角色/新剧情的 bundle 资源)、资源 catalog、剧情索引、封面、
  插件 DLL、玩家文档、启动器本体。
  - 更新内容可能较大,请耐心等待日志区走完;中途失败可重试,已装部分保留;
  - 若更新了启动器本体,完成后启动器会自动重启一次(替换动作在退出后进行);
  - 点「更新」时若提示「需重装」:说明你手里的完整包基线太旧,增量更新无法跨越,
    请下载最新完整包(存档与设置不受影响,可只替换游戏目录);
  - 按钮上出现「有更新」时表示检测到新版本,点它即可更新;
  - 平时不更新也完全可以正常游玩。

【首次准备】
  每个新安装的包第一次启动时自动执行(不联网):
  解除"来自其他计算机"的文件标记 -> 修正离线配置 -> 设置离线身份 ->
  把包内 catalog 与运行配置播种到存档目录 -> 全项自检。
  之后不再重复执行;需要重做时可点「高级 -> 修复」。

【高级】
  自检      只读检查 13 项本机条件(主程序/注入入口/插件/索引/封面/配置/
            离线身份/catalog 种子/缓存完整性/文件标记/端口/版本文件),
            按提示处理未通过项。
  索引探针  只读验证剧情索引、封面数量、配置与端口是否可绑定(不启动游戏)。
  修复      重写离线配置为正确的离线档、设置离线身份、播种 catalog、解除文件标记、
            归档超大日志、重跑自检。不会删除存档或游戏内容。
  打开日志  用资源管理器打开 BepInEx 目录,反馈问题前请取走 LogOutput.log。

【日志区颜色】
  亮色 = 成功/说明,琥珀色 = 警告,红色 = 失败。

【命令行(可选)】
  DotabyssOfflineLauncher.exe --smoke <输出文件>   冒烟自检(调试用)
  DotabyssOfflineLauncher.exe --game-dir <目录>    指定游戏目录

【遇到问题】
  1. 双击包根目录的 check_health.bat 看 14 项结构检查;
  2. 启动器「高级 -> 自检」;
  3. 仍不能解决,带上 BepInEx\LogOutput.log 与自检结果反馈。
  详细排障见 安装排障.md。
