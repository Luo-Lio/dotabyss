# ドットアビスX 离线版 · 使用说明

本包是**ドットアビスX(Dot Abyss X)**的完整离线版:游戏本体 + 离线插件 + 剧情浏览器。
**不需要 DMM 账号、不需要联网**即可游玩(除「更新」按钮外)。

---

### 公告

- **最新公告以启动器界面上方的公告区为准**(随「更新」刷新)。
- **别把 GitHub Release 当整包**:Release 里是**增量更新资产(散件)**,不是给新玩家解压即用的完整包,
  也不是插件包。整包请下载作者发布的**完整包 zip**(约 8 GB)。
- 离线包与在线版**共用同一份存档/设置**(详见「四、存档与配置」);两边都玩请**不要同时运行**。

---

## 一、安装

> ⚠️ 请确认你下的是**完整包 zip(约 8 GB)**,而不是 GitHub Release 里那堆散件 —— Release 是**增量更新
> 资产**,单独下载它们凑不出可玩的整包。包根应有 `launcher.json`(记录更新仓库,官方完整包自带);
> 若是自行拼装的包,请自己建一个内容为 `{"github_repo": "Luo-Lio/dotabyss"}` 的 `launcher.json`,
> 否则「更新」会提示「未配置仓库」。

1. 把压缩包**完整解压**到一个文件夹(推荐放在非系统盘,例如 `D:\dotabyss`;
   解压后约 8 GB,请预留 16 GB 以上空间)。
2. 解压后确认目录里有这些关键内容:

   | 名称 | 作用(不要删) |
   | --- | --- |
   | `ドットアビスX.exe` | 游戏主程序 |
   | `DotabyssOfflineLauncher.exe` | 离线启动器(**请用它启动游戏**) |
   | `winhttp.dll` | BepInEx 注入入口 |
   | `BepInEx\` | 离线插件本体(含 `catalog_seed\` 资源索引种子) |
   | `ドットアビスX_Data\` | 游戏数据(内含离线所需的全部资源缓存) |

3. **不要**用 DMM GAME PLAYER 启动(那是网络版)。也不要删除或移动
   `ドットアビスX_Data\Caches\` —— 离线资源全部来自这里,删了会黑屏。

> 首次解压后 Windows 可能给文件加上"来自其他计算机"的下载标记。
> 启动器第一次运行时会自动解除;也可以在「高级 → 修复」里手动执行。

## 二、启动

双击 **`DotabyssOfflineLauncher.exe`**,点「开始游戏」。

- 第一次启动会先做一次「首次准备」(解除文件标记、修正离线配置、检查存档设置、
  把包内 catalog 播种到存档目录、自检),约 10~30 秒,日志区会逐条显示结果。
- 之后每次启动秒开。也可以直接双击 `ドットアビスX.exe`,但推荐走启动器
  (启动器会先补齐 catalog,并把常见问题自动修好)。
- 每次点「开始游戏」前,启动器还会做一次**轻量的存档健康检查**:把游戏**解不开的设置值**先备份
  (存到 `BepInEx\prefs_backup_*.json`)再隔离,防止因此黑屏;通常瞬间完成。

## 三、剧情浏览器(核心功能)

游戏内按 **F7** 打开/关闭剧情列表(可在配置里改键)。

- **全部剧情一览**:主线、活动、角色剧情共 1200 余篇,带封面缩略图,支持搜索与分类筛选。
- **直接播放**:点封面即可播放,不再依赖服务器下发。
- **R18 过滤**:列表内可切换 R18 内容的显示/隐藏;配置里也可设定播放时跳过 R18 段。
- **资料室全开放**:主线回想、活动回想、角色剧情均不受进度/亲密度限制。
- **剧情内跳过**:播放时按 **F8** 直接跳到当前段结尾(含 R18 后篇)。
- **面板自适应窗口**:拖动 / 最大化游戏窗口时,剧情面板会**实时跟随重新缩放布局**,
  不会停在旧尺寸(全屏与窗口自由切换均可)。

## 四、存档与配置

- 存档:`C:\Users\<用户名>\AppData\LocalLow\EXNOA LLC_\ドットアビスX\`
  - ⚠️ **这个目录与网络版(官方在线版)是同一个**:离线包与网络版**共用存档与系统配置**,
    两边不会各存一份。若你两边都玩,请**避免同时运行**,并尽量在退出后再切换。
    (2026-10-11 实测更正:旧版说明里的「`_offline` 独立目录、互不干扰」并不成立。)
  - 卸载/重装离线包时,这个目录**可以保留**(存档不随游戏目录删除)。
- 插件配置:`BepInEx\config\dotabyss.storyviewer.cfg`
  - 常用项:`ToggleKey`(列表快捷键,默认 F7)、`SkipKey`(跳过快捷键,默认 F8)、
    `UiScale`(界面缩放,0 = 自动)。
  - 游戏启动时读取,改完重启游戏生效。

## 五、更新(可选,两条通道)

更新有两种方式,**更新内容完全相同**,只是取文件的渠道不同:

- **在线更新**:主界面的「更新」按钮,从 GitHub 获取(**需要联网,且能连上 GitHub**)。
- **离线更新包**:网络连不上 GitHub 时,用作者从其它渠道(网盘/群文件等)发布的
  「离线更新包 `.zip`」本地导入。全程**不联网**。

更新涵盖的内容:

| 内容 | 说明 |
| --- | --- |
| 客户端本体 | 游戏程序、DLL 等,按文件校验只下载变化的部分(可能几百 MB) |
| 素材增量 | 新角色/新剧情所需的 bundle 资源 |
| 资源 catalog | 资源索引(新素材必须配套) |
| 剧情索引/封面 | stories.json 与封面图 |
| 插件 DLL | StoryViewer 本体(版本号会显示在启动器右上角) |
| 玩家文档 | 本说明等文档 + check_health.bat |
| 启动器本体 | 更新后自动重启一次启动器完成替换 |

- 平时不点它也能完整游玩,内容就是打包时的版本。
- 按钮上出现 **「有更新」** = 检测到新版本;点它执行更新。
- 若按钮变成 **「需重装」**:官方换过完整包基线(例如换了游戏本体大版本),
  增量更新无法跨越,请重新下载完整包。**存档与插件配置不受影响**,
  可以只替换游戏目录、保留存档目录(`AppData\LocalLow\EXNOA LLC_\ドットアビスX\`)。
- 「高级」里还有:自检、索引探针、修复、打开日志、**离线更新包**。

### 用「离线更新包」更新(连不上 GitHub 时)

1. 从作者发布的渠道下载「离线更新包 `.zip`」(文件名形如 `ドットアビスX_更新包_<版本>.zip`),
   保存到本机任意位置(无需解压)。
2. 先**完全退出游戏**(游戏运行中会拒绝更新)。
3. 打开启动器 →「高级 ▾」→ 点「**离线更新包**」→ 选中刚下载的 `.zip` → 确定。
4. 启动器会解压、校验清单与摘要,然后走与在线更新**完全相同**的流程
   (逐文件比对、只更新有变化的部分、失败自动回退),完成后日志区提示「更新完成」。

> 说明:离线更新包就是 GitHub Release 那一整套文件打的本地 zip,内容和在线一模一样;
> 若包内基线与本机不一致,同样会提示「需重装」,请改下载新的完整包(存档与配置不受影响)。

## 六、出问题时

1. 先在启动器点「高级 → 自检」,按提示处理未通过项;
2. 仍不行就点「高级 → 修复」,再试;
3. 还不行,请把 `BepInEx\LogOutput.log` 发给作者,并附上「自检」的截图。

更多排障步骤见同目录 **`安装排障.md`**;启动器按钮的详细说明见 **`启动器使用说明.txt`**。
