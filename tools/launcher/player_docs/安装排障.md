# 安装与排障(ドットアビスX 离线版)

先跑一遍 **`check_health.bat`**(双击即可):它会把 14 项结构检查打印出来,
绝大多数问题看它最后一行的 `RESULT` 就能定位。下面按症状列出常见原因与处理。

---

## A. 启动器/游戏起不来

### A1 双击启动器没反应,或者窗口一闪就没了
- **杀毒软件拦截**(PyInstaller 打包的 exe 常被误报):把整个游戏目录加入信任/白名单,
  再试一次。实在不行,直接双击 `ドットアビスX.exe` 也能进游戏。
- 不确定是不是被拦:看杀毒软件的"隔离区/防护记录"。

### A1b 更新完启动器后,出现 `DotabyssOfflineLauncher.exe.new` 且启动器没变新
- 这是"退出后替换"没走完的残留(替换需要一个短暂的命令行窗口完成)。
  **再双击一次启动器**即可:启动时会自动完成替换再退出,然后再正常启动。
- 修正后 `.new` 文件会消失;若长期存在且启动器版本没变,把该文件删除后重新更新。

### A2 提示缺少 DLL / 报 `0xc000007b` 之类
- 解压不完整(常见于中断、空间不足)。重新解压,
  确认 `dotnet\` 与 `D3D12\` 两个目录存在。

### A3 游戏窗口出现但黑屏 / 卡在加载 / 频繁弹错误
- 九成是 **`ドットアビスX_Data\Caches` 不完整**。运行 `check_health.bat`,
  看 `Caches entries` 是否低于 10000;低于就重新解压完整包。
- 日志定位:`BepInEx\LogOutput.log` 里搜 ` 404`,行数 > 0 说明有资源没命中缓存。
- 把 `Caches` 目录排除在杀毒扫描之外,避免被"清理"掉。

### A4 新机器第一次启动就卡在标题/一直转圈
- 先按 `check_health.bat` 的 `[12/14] offline identity` 与 `[13/14] catalog seed` 两项确认:
  身份应为 `*_offline`,种子目录应有两个文件(约 13 MB)。
- 缺任一项:点启动器「高级 → 修复」(会重建身份与播种 catalog,不联网),再试。
- 仍不行就反馈:附上 `BepInEx\LogOutput.log`、`check_health.bat` 输出,
  以及 `C:\Users\<用户名>\AppData\LocalLow\EXNOA LLC_\ドットアビスX_offline\` 的目录清单。

## B. 插件相关

### B1 游戏能进,但 F7 打不开剧情列表
1. 先看 `BepInEx\LogOutput.log` 里有没有这样一行:
   `StoryViewer <版本> 加载完成:按 F7 打开剧情列表…`
   - **没有** → 插件没被加载:`winhttp.dll` 丢失或被隔离、或 `BepInEx\core` 被杀软删了。
     用 `check_health.bat` 确认,必要时重解压。
   - **有** → 请**在游戏主页(Home)场景**按 F7;其他场景列表会自动关闭。
2. 快捷键被别的软件抢了:编辑 `BepInEx\config\dotabyss.storyviewer.cfg` 里的
   `ToggleKey`,换成别的键(如 F6/F9),重启游戏。

### B2 剧情播放中按 F8 不跳转
- 日志里如果是 `[跳过] 按 F8:当前不在剧情场景` → 说明当时没有可跳过的剧情段。
- 想换键:改配置 `SkipKey` 后重启游戏。

### B3 中文/日文显示成方块
- 本包自带翻译与字体缓存(`BepInEx\plugins\AbyssMod\`),**不要删除**。
- 若日志提示 `未能加载界面字体`,通常还是缓存被清理:重解压该目录。
- 面板字体不影响功能,剧情文字字体问题优先检查 AbyssMod 目录完整性。

### B4 端口 18923 被占用
- 一般是上一次游戏进程没退干净。打开任务管理器,结束 `ドットアビスX.exe` 后重开。
- `check_health.bat` 的 `[9/14]` 会报告端口状态;游戏没开却显示占用时,可用
  `netstat -ano | findstr 18923` 查是哪个进程。

### B5 日志里出现 `catalog` 相关报错 / 资源 404 突然变多
- 检查包内 `BepInEx\plugins\StoryViewer\catalog_seed\` 是否有 `catalog_1.bin`
  与 `catalog_1.bin.hash`;缺失就重新解压完整包(或用启动器更新一次)。
- 更新过素材(新角色/新剧情)后,启动器会把 catalog 一并写入包内与存档目录;
  若两者不一致,点「高级 → 修复」会以包内种子为准重新播种。

## C. 离线配置被改坏

游戏与服务器"较劲"(报 `初期化に失敗しました`、反复弹错误)时,先确认配置为离线档。
打开 `BepInEx\config\dotabyss.storyviewer.cfg`,`[Offline]` 段应满足:

```
OfflineAuth           = true
OfflineApi            = true
RedirectAssetServer   = true
ServeCachedBundles    = true
SkipRequestEncryption = true
ForceDmmSdkSuccess    = true
CaptureForward        = false
```

改错不用手抄:点启动器「高级 → 修复」会自动写回(不覆盖其他设置)。

## D. 存档

- 位置:`C:\Users\<用户名>\AppData\LocalLow\EXNOA LLC_\ドットアビスX_offline\`
  (结尾 `_offline` 是离线版专用身份,与网络版存档完全分开,两边都玩不会互相覆盖)。
- 该目录被清理工具删除后会"从头开始";建议把它也加入杀毒/清理软件的排除项。
- **备份存档 = 复制这个目录**。
- 目录里还有离线运行所需的两样东西:资源 `catalog` 与 `AbsfRuntimeConfig.dat`
  (首次启动由启动器自动播种)。删掉不影响启动器修复,但**不要手动删掉后再直接从
  exe 启动游戏**,这样会用不到 catalog。

## E. 更新相关

- 点「更新」提示 **未配置仓库**:说明 `launcher.json` 里没有 `github_repo`
  (官方完整包会带;自编译包需要自己填)。
- 按钮显示 **「需重装」**:完整包基线已更新,请下载最新完整包。存档与设置不受影响。
- 更新失败先确认**游戏已退出**(游戏运行时禁止更新),再检查网络。
  直连 GitHub 不通时启动器会自动改用系统代理重试;仍失败就换个网络环境。
- 更新会覆盖:客户端本体(游戏程序/DLL)、素材增量(新 bundle)、资源 catalog、
  剧情索引、封面、插件 DLL、启动器本体、玩家文档;
  **不会动你的存档**,也不会用旧文件覆盖你的 `app.info`(离线身份)。
- 客户端本体是按文件校验的:只有内容变化的文件才会重写,更新包本身可能上百 MB,
  请耐心等待日志走完。

## F. 反馈问题时请附上

1. `BepInEx\LogOutput.log`(整个文件);
2. `check_health.bat` 的完整输出(截图或文本都可以);
3. 启动器「自检」结果(若有未通过项);
4. 问题描述:什么时候出现、能不能复现、做过什么操作。
